# Wonder IV · prompts de las maravillas y del mapa (completos, uno por imagen)

Sirven para quitar los dibujos vectoriales del asentamiento: así las siete maravillas y el fondo tendrán el mismo estilo que los edificios. Cada prompt se pega **tal cual**. Las siete maravillas van sobre **fondo verde liso `#00FF00`** (como las piezas y los edificios) y son **cuadradas 1:1**; el mapa es un paisaje **16:9** sin fondo verde.

Para que todo case, **genera primero el mapa (prompt 8) y las maravillas después en la misma conversación o con el mismo estilo**; si una sale con otra luz, pídele «same lighting from the top left as the other images».

Orden recomendado: 8 (mapa), 1 a 7 (maravillas).

## Si una imagen sale mal

Pega esto en la misma conversación y vuelve a generar, sin tocar el prompt:

```
Regenerate the same image. Keep everything identical except this one fix: the background must be one flat uniform #00FF00 green with nothing on it (for the monuments), and the whole object must be fully inside the image with an even margin on all sides. Same lighting from the top left as the previous images.
```

Cuando me pases las imágenes con esos nombres, las integro igual que los edificios: las maravillas terminadas en color, las que aún no has construido en gris y atenuadas, y el mapa como fondo del asentamiento.
